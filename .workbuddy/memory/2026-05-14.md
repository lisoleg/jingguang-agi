## AGI 12.0 界面重构 - 三栏布局

### 用户需求
用户不喜欢之前的界面设计，要求：
1. **对话界面要简洁** - 不要在中间出现脑图
2. **分析数据放在两侧** - 各种分析仪表盘在左侧
3. **核心是一个关系图** - 右侧显示多轮对话的问答关系链条

### 新布局设计
```
┌──────────┬──────────────────────┬──────────────┐
│ 左侧面板  │     中间对话区域       │  右侧DAG图   │
│ (分析仪表)│                      │              │
│  - 熵    │  - 输入框            │  问答关系链  │
│  - 五行  │  - 对话历史          │              │
│  - 锚定  │                      │              │
└──────────┴──────────────────────┴──────────────┘
```

### 实现内容
1. **左侧面板（320px）**：分析仪表盘
   - 模式切换（对话/Goal）
   - 输入框
   - 三相熵仪表盘
   - 五行耦合仪表盘
   - 介质锚定验证
   - 模块分析面板

2. **中间区域（flex:1）**：对话界面
   - 标题栏 + 对话数量徽章
   - 对话历史（可滚动）
   - 输入区（可切换对话/Goal模式）

3. **右侧面板（400px）**：DAG关系图
   - 问答关系链可视化
   - 问题节点（紫色）
   - 答案节点（绿色）
   - 追问/引用关系（虚线）
   - 底部图例说明

### 技术实现
- 重写了 CSS 布局（Flexbox 三栏）
- 更新了 HTML 结构
- 重构了 JavaScript（移除旧的画布引用，适配新的 DAG SVG）
- DAG 渲染函数使用紧凑的网格布局

## 陈天桥测试 AI 自动答题功能

### 用户需求
点击"开始测试"后，AI 应该自动一道道的答题，而不是让用户手动选择答案。

### 实现方案
1. **新增属性**
   - `aiAutoMode`: 标志是否为AI自动答题模式
   - `aiAnswering`: 标志AI是否正在答题中

2. **核心方法**
   - `start()`: 启动测试，设置 `aiAutoMode = true`
   - `aiAutoAnswer()`: AI自动答题核心逻辑
     - 随机"思考"时间（300-800ms）
     - 选择正确答案
     - 显示 AI 选中的选项
     - 自动跳转到下一题
   - `showQuestionInChat()`: 显示题目后自动触发AI答题
   - `gotoQuestion()`: 跳转题目时，如果是AI模式且未答则触发答题
   - `selectAnswer()`: AI模式下禁止用户手动选择
   - `submit()`: AI模式下不需要确认对话框

3. **UI改进**
   - 左侧面板显示"AI自动答题中"状态
   - 带有动画的"AI正在答题..."提示
   - 中间对话区显示"AI正在思考..."动画
   - AI选中的选项显示绿色高亮和 ✓ AI选 标记

### 修改的文件
- `static/index_agi12.html`
  - CHEN_TEST模块新增aiAutoMode/aiAnswering属性
  - 新增aiAutoAnswer()方法
  - 修改start()/showQuestionInChat()/gotoQuestion()
  - 修改selectAnswer()阻止手动答题
  - 修改submit()跳过确认
  - 新增CSS样式: .ai-thinking, .ai-thinking-dot, .ai-selected
  - 同步更新至index.html
