## 任务：修复对话计数为0 + 消息发送卡住问题（#404 后续）

### 问题
- `qa-badge` 显示 "0 对话"，但对话区有用户消息
- 发送消息后按钮卡在"分析中..."，迟迟得不到答复

### 根因
1. `pushMsg` 中 `addQA2DAG` 可能抛出异常，导致 `updateQABadge()` 不执行
2. `doMainChat` 中 `pushMsg` 在 `try` 块外，异常会中断整个函数，`STATE.loading` 永久为 true
3. `updateQABadge` 没有空值保护，`threads`/`qa_pairs` 未定义时会崩溃
4. `addQA2DAG` 中直接访问 `stn.active_node_id` 没有检查 `stn` 是否存在

### 修复
- `pushMsg`: 添加 try-catch 包裹 DAG 更新逻辑，确保 `renderHistory`/`updateQABadge` 始终执行
- `addQA2DAG`: 完整 try-catch + `stn` 空值检查 + `type==='user'` 处理 + `node_type` 动态设置
- `doMainChat`: `pushMsg` 移入 try-catch，防止 `STATE.loading` 永久卡住
- `updateQABadge`: 添加空值保护链 `(STATE.dag_data && STATE.dag_data.threads) || []`
- Commit: f2381c2

## 任务：修复 DeepSeek API 500 错误 + 增强 LLM fallback（#404 后续）

### 问题
- 用户提问后收到 `[DeepSeek对话错误: 500 {"error":{"message":"Internal Server Error"...}}]`
- 前端显示原始错误信息，对用户不友好

### 根因分析
1. **DeepSeek API 间歇性 500** —— 服务端问题，非我方代码问题
2. **`chat_with_image` 无 fallback** —— `taiyi_llm_enhancer._call_llm_core` 调用 `active_backend.chat_with_image()`，失败时不会自动切换其他后端
3. **前端错误提示不友好** —— 直接显示 `[DeepSeek对话错误: 500 ...]`

### 修复
- `local_llm.py`: 为 `LocalLLM` 添加 `chat_with_image` 方法（带多后端 fallback）
  - 优先尝试活跃后端的 `chat_with_image`
  - 失败时依次尝试其他后端的 `chat_with_image` → `chat` → `generate`
  - 自动切换活跃后端到成功的后端
- `index_agi12.html`: 友好化错误提示
  - DeepSeek 500 → "服务端暂时不可用，已尝试切换备用后端"
  - 超时 → "请求超时，检查网络"
  - 未配置 API Key → "请添加 DEEPSEEK_API_KEY"
  - 所有后端不可用 → 完整排查建议
- Commit: da7a58f

### 验证
- 直接调用 `llm.chat_with_image('你好')` → DeepSeek 正常返回
- 通过 `enhancer.generate('你认为人应该活到多少岁')` → 正常返回（含太乙三答格式）
- DeepSeek 当前可用，500 为间歇性问题；fallback 机制确保下次出现问题时自动切换
