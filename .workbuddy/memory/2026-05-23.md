## Bug修复: input length too long (taiyi_llm_enhancer.py) ✅
- **错误**: `400 input length too long (c50773a.../d4544775-...)` — 来自Dashscope API (通义千问)
- **根因**: `generate()` 构建的 messages 过长（system_prompt含RAG知识库+记忆上下文 + 多轮history），超出模型上下文窗口
- **修复内容** (`taiyi_llm_enhancer.py`):
  1. 新增 `_estimate_tokens()`: 粗略估算token数（中文1.5字/token，英文3.5字符/token）
  2. 新增 `_truncate_messages()`: 智能截断——保留system prompt(截断到~2000 tokens) + 从后往前保留最近N轮对话
  3. 重构 `_call_llm()` → 调用前先 `_truncate_messages()`，捕获"input length"/"too long"异常后更激进截断(max_tokens=6000)重试一次
  4. 新增 `_call_llm_core()`: 从 `_call_llm` 拆出实际调用逻辑，供重试复用
  5. 修复 `_call_llm_stream()` 降级路径：原来调用 `_call_llm()`（会递归截断），改为调用 `_call_llm_core()` 避免重复截断
  6. `_build_system_prompt()` 上下文长度限制收紧：RAG knowledge_context 2000→1200，memory_context 1500→800/1000→600
- **踩坑**: `_call_llm_core` fallback分支 `self.llm.generate(prompt, max_tokens, temperature)` 缺少逗号（原代码bug），已一并修复
