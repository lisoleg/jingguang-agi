### 技术细节

#### API请求格式
```json
POST /api/cognition/test
{
  "mode": "quick" | "full",
  "num_questions": 12 | 300
}
```

#### API响应格式
```json
{
  "success": true,
  "mode": "quick",
  "num_questions": 12,
  "questions": [...],
  "test_id": "CHEN_1234567890_1234",
  "timestamp": "2026-05-19 12:00:00"
}
```

#### 前端JS函数调用流程
1. 用户选择模式（快速/完整）→ `CHEN_TEST.mode` 设置
2. 点击"开始测试"按钮 → `CHEN_TEST.startTest()`
3. 调用API获取题目 → `fetch(CHEN_API_URL, ...)`
4. 渲染第一题 → `CHEN_TEST.renderQuestion()`
5. 用户答题 → `CHEN_TEST.selectOption(idx)`
6. 下一题/上一题 → `CHEN_TEST.nextQuestion()` / `CHEN_TEST.prevQuestion()`
7. 提交测试 → `CHEN_TEST.confirmSubmit()` → `CHEN_TEST.finishTest()`
8. 计算结果 → `CHEN_TEST.renderResults()`
9. 根据模式显示不同结果 → `renderQuickResults()` 或 `renderFullResults()`
