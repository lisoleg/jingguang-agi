❓ 净光哥 AGI 使用说明
💬 对话模式
标准对话：在底部输入框输入问题，AI将调用24个认知模块协同分析
追问：直接继续输入，系统自动关联当前话题形成多轮对话
话题切换：输入新话题时，系统自动开创新线索（DAG独立分支）
🎯 Goal模式
目标驱动：输入复杂目标如"分析XXX的架构"，系统启动多步Goal推理
子目标分解：自动将大目标拆解为可执行的子目标序列
进度追踪：在对话区显示Goal执行进度和评分
📊 左侧分析仪表盘
三相熵耦合：Si=信息熵, Sg=生成熵, Sc=认知熵，反映当前认知状态
五行耦合：木/火/土/金/水对应认知功能的五个维度
介质锚定：验证语义一致性（能量/语义/因果/经验四重约束）
介质共振：g_C相位锁定度表示认知场与现实场耦合强度，心斋状态(S_C<0.15)为最佳认知
九卦修身：履→谦→复→恒→损→益→困→井→巽，九步降熵从高S_C到心斋
陈天桥测试：21道认知能力综合测试，由AI实时生成题目（苏格拉底诘辩模式）
四象相干模态：刚性耦合(三国)、沸腾反抗(水浒)、取经相干(西游)、熵增终局(红楼)
🔗 右侧对话关系链（苏格拉底拓扑）
节点：Q=问题, A=回答，点击节点跳转对应对话
关系类型：问答/引用/整合/诘辩（T3.1诘辩涌现定理）
引用(REF)："问题Q3的观察者尺度参数是什么意思" → 追问Q3
整合(INTEGRATE)："将前面三个回答整合为一个论文" → 链接A1+A2+A3
诘辩(ELENCHUS)："何以见得？请证明" → 苏格拉底式追问
折叠：点击▼按钮折叠/展开对话关系链
全屏：点击⛶按钮全屏查看对话关系链
